Terminal kaise kholein

Terminal ek kaali ya neeli window hai jisme hum computer ko likhkar kaam bolte hain. Start menu mein PowerShell likho aur khol lo.

Neeche har command ke saath Copy button hai. Copy dabao, terminal mein right-click karke paste karo, phir Enter dabao. Ek command khatam ho jaye, tab agli chalana.

6
python -m venv .venv

Is project ke liye ek alag dabba banata hai, taaki iska saaman baaki computer se na mile.

Panna hai kya?

Socho tumhare paas 100 page ki book hai aur ek sawal ka jawab chahiye. Ek dost hai jo book padhkar sahi page dhoondta hai, usi se jawab deta hai, aur page dikhakar kehta hai: "yeh dekho, yahan likha hai." Book mein na ho to seedha bolta hai: "book mein nahi hai."

Panna wahi dost hai, ek pyara sa robot. Tum PDF ya TXT file do, sawal poocho, aur woh sirf usi file se jawab dega. Panna ka matlab hai page, isliye app ek purane phate register jaisi dikhti hai.

Yeh kaise kaam karta hai: ek kahani

Maan lo ek library hai, aur usme hamara robot kaam karta hai.

1. Book aayi (Upload)

Tumne robot ko sample handbook di.

2. Padhna (Extract)

Robot PDF ke har page se text nikaal leta hai. Yeh kaam pypdf karta hai.

3. Tukde karna (Chunking)

Poori book ek saath yaad rakhna mushkil hai, isliye robot use chhote tukdon mein kaat deta hai, har tukda lagbhag 500 akshar ka. Har tukde mein pichhle tukde ka thoda hissa bhi rehta hai (80 akshar), taaki koi baat beech se na kate. Isko overlap kehte hain.

4. Numbers banana (Embedding)

Computer shabd nahi, numbers samajhta hai. Sentence Transformers har tukde ko 384 numbers mein badal deta hai. Jinka matlab milta-julta ho, unke numbers bhi paas-paas hote hain. "Late fine" aur "der se lautane ka paisa" paas aa jayenge.

5. Almari mein rakhna (FAISS)

FAISS ek smart almari hai jo un numbers ko rakhti hai aur milta-julta tukda turant dhoondh deti hai.

6. Tumne sawal poocha

Sawal bhi numbers mein badalta hai. FAISS sabse milte-julte 4 tukde nikaal deta hai.

7. Pehla pehredaar (Score gate)

Har tukde ka ek score hota hai ki woh sawal se kitna milta hai. Agar sab bahut door hain, to robot AI ko bulata hi nahi aur bol deta hai: document mein nahi mila.

8. Doosra pehredaar (Prompt)

AI ko saaf rules diye jaate hain: sirf in tukdon se jawab do, apne se kuch mat banao, nahi mile to mana kar do. Yeh rules hi prompt hain.

9. Jawab (Ollama)

Ollama par chal raha model tukde padhkar jawab likhta hai. Jawab screen par shabd-shabd aata hai, aur neeche woh text dikhta hai jahan se jawab aaya.

Sir ye pooch sakte hain

RAG kya hai?

Pehle document se sahi text dhoondte hain, phir wahi text AI ko dete hain. Isse jawab document se aata hai, AI ki yaad se nahi.

Chunking aur overlap kyun?

Poora document AI ko ek saath nahi de sakte, aur chhote tukdon par search behtar hoti hai. Overlap isliye ki koi baat do tukdon ke beech se kat na jaye.

Embedding kya hai?

Text ko numbers mein badalna. Yahan har tukda 384 numbers ka hai. Same matlab wale text ke numbers paas hote hain.

FAISS kya karta hai?

Numbers store karta hai aur sawal ke sabse paas wale tukde dhoondta hai. Hum IndexFlatIP use kar rahe hain, jo cosine similarity se exact search karta hai.

Bot jhooth kyun nahi bolta?

Do guard hain. Score kam ho to AI ko bulate hi nahi. Aur prompt kehta hai ki sirf diye gaye text se jawab do, warna mana kar do. Chhota model kabhi galti kar sakta hai, isliye source text bhi dikhate hain taaki check ho sake.

Paid API ke bina kaise chala?

Ollama model ko laptop par hi chalata hai, aur embeddings bhi local hain. Internet sirf pehli baar download ke liye chahiye.

UI to alag hai, Gradio kahan hai?

Yeh Gradio ka Server mode hai. rag/server.py dikhao. Stock Gradio chat /classic par khulta hai.

Yeh project kisne banaya?

Jo sach hai wahi bolna. Agar kisi ki ya AI tool ki madad li hai to bata do. Isliye upar wali kahani achhe se samajh lo, taaki tum khud explain kar sako.
